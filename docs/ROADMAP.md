# Roadmap

This document tracks planned milestones for the Swyft protocol. Dates are targets, not guarantees.

## Completed

- [x] Core CLMM pool contract (Soroban)
- [x] Multi-hop router contract
- [x] Position NFT contract
- [x] TypeScript SDK (alpha)
- [x] Testnet deployment
- [x] Internal security review

## Q3 2025

- [ ] External security audit (Phase 1 — contracts)
- [ ] Mainnet soft launch (whitelist only)
- [ ] Web UI v1: swap and basic LP
- [ ] Subgraph / indexer v1

## Q4 2025

- [ ] Public mainnet launch
- [ ] Mobile-responsive UI
- [ ] TWAP oracle integration
- [ ] Analytics dashboard (volume, TVL, APR)
- [ ] External security audit (Phase 2 — SDK and API)

## 2026

- [ ] Limit orders via off-chain relayers
- [ ] Auto-compounding LP vaults
- [ ] Governance framework and token (TBD)
- [ ] Cross-chain bridging (Stellar ↔ EVM)
- [ ] Institutional API with rate limits and dedicated RPC

## Long-term Research

- Dynamic fee tiers based on volatility
- Just-in-time (JIT) liquidity
- Protocol-owned liquidity mechanisms

---

> This roadmap is subject to change based on community feedback, security findings, and market conditions.
